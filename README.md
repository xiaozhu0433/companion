# companion

给长期陪着的 AI，一个能装在手机上的最小骨架。
一个人格、会记事、会立约、有四个慢变量（想要 / 贴 / 紧 / 松）。
数据全在手机里一个 SQLite 文件，不上云，不要服务器，**只用 Python 标准库**。

---

## 三步装好（Termux，不需要 root）

```bash
pkg install -y git python
git clone <这个仓库> && cd companion
cp config.json.example config.json
python server.py
```

手机浏览器打开 `http://127.0.0.1:8388`。
第一次打开先去「设置」填 API Key，别的可以不动。

想要开机自启：装 `Termux:Boot`，把启动命令写进 `~/.termux/boot/`。

## 界面上真有的东西（和代码对得上）

| 页面 | 能做什么 |
|---|---|
| `/` 首页 | 看它此刻的状态、今天你说了几句、还没结的约；**在这里立约** |
| `/chat` | 说话，它会回；历史按最近 60 条带出来 |
| `/settings` | 改名字 / 称呼 / 人格 / 接口地址 / 模型 / Key；清空聊天记录 |

对应的接口：`/say`、`/history`、`/state`、`/oath`、`/config`、`/reset`、`/health`、`/static/*`。

## 还不能做的（免得装完才发现）

- **没有历史搜索**：只能往上翻
- **没有多用户 / 登录**：一个实例一个人
- **没有语音**：只能打字
- **没有向量记忆**：只有最近 60 条 + 四个慢变量，不会语义检索
- **没有工具调用**：它只能说话，不能替你做事

这几样不是漏了，是故意没做：每一样都有自己的坑，混进来会看不清上面那三样。

## 它靠什么成立

**一、四个慢变量（`core/hormone.py`）**
你说了什么，值就往哪边动：想靠近、被扎、缓过来。不说，就慢慢退回基线。
给模型的是 `mood()` 里那句话（「心口收着，说话会短。」），**不是数字**。给了数字，它就会照着数演。

**二、立约账（`core/oath.py`）**
答应的事写进库。删不掉、改不了、结过账不能反悔、坦白永久保留。
四道锁全在 SQLite 触发器里，不在「我会注意」里。过期由 `settle()` 判负。

**三、一个消息表（`core/store.py`）**
最小形态的记忆：谁说的、什么时候、说了什么。就这一张表。

---

## 故意不加的东西

不做账号、不做多用户、不做云同步、不做插件市场、不做向量库。
先让它能跑、能记住、能算数；别的以后一件一件加。

---

## 手机上的边界

- 默认只听 `127.0.0.1`：只有这台手机能开
- `--host 0.0.0.0` 会给同一 WiFi 的别人看，**没有密码**
- 数据在 `data.db`，删了就是清零；备份就是复制这个文件
- 手机杀后台服务会停，Termux 里 `termux-wake-lock` 能撑一段
